Profile CSS generator

Ever wanted a custom profile, but couldn't spare the time to learn to code? This is for you!
You can fil in the fields with hex codes. If you don't have experience with them, I find Color-Hex is a great resource.
https://www.color-hex.com/
You can also use the color selectors to the right of each field.
Instructions:

-Body Background is the big background, usually where images go
-Box Background is for your greeting, signatre, etc backgrounds.
-Accent Background is the title boxes and a few accent colors around the profile.
-Text Color is the main text color of your profile. -Text Accent is the color for links and other accents.
You can use color names(red, blue, transparent), hexes (#FFFFFF), RGB/RGBA, etc, just keep it readable.
>You will need to be on a laptop/PC, pasting codes is broken on touchscreens!
>Choose the main background, you can use image urls or a hex code.
>Choose the boxes background, this will be for your greeting, signature, recent posts, etc.
>Choose accent background, this will be your title/headers, etc.
>Choose text color, please make sure it's readable so everyone can see it!
>Choose accent text, this will be the color of text on the headers.
>Click "Generate"
>Highlight EVERYTHING in the box below.
>Copy, right-click then copy or Ctrl+C.
>Go to your profile > Customize Profile > Profile Styles.
>Paste the code, right-click then Paste, or Ctrl+V.
>Save & View

Optional, but if you like the code, I recommend saving the code in a private profile page:
>Profile > Manage Pages > Add New > Paste the code.
If you need to get the code later, just go to edit the page and copy the code.

If it doesn't work, you can post on the forums for help and I'll try to troubleshoot for you. Please provide screenshots and detailed steps; "it didn't work" tells me nothing ~

Preview is for visual purposes only! Results with image backgrounds may vary.
